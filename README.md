# BuyHaat

BuyHaat is a mobile-first multi-vendor marketplace project.

## Current foundation
- Home page
- Search UI
- Categories
- Product listing
- Dynamic product detail route
- Basic order button placeholder
- Following page
- Add Product page placeholder
- Chat page placeholder
- My Store page placeholder
- Responsive bottom navigation

## Planned backend
Supabase will be added in later steps for:
- Email authentication
- Store creation
- Products
- Product images
- Orders
- Following
- Realtime chat
- Reviews
- Seller dashboard
- Row Level Security

## Deployment
This project can be deployed to Vercel as a static frontend during the initial stages.
